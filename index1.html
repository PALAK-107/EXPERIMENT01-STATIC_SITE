Simple Static Website

This page demonstrates a basic static website that can be hosted using GitHub Pages.

Process

  1. Create a github repository.
  2. Create a branch for changes.
  3. Commit and push the changes.
  4. Merge the branch into the main branch.
  5. Enable GitHub Pages for the repository.
  6. DONE!

About

GitHub allows us to create, store, manage, and share your software code, while GitHub Pages can publish static HTML, CSS and JavaScript websites without the need to buy for hosting a site.
